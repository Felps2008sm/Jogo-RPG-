# CHANGELOG

## [1.0.0] - 2026-04-29

### Adicionado
- Sistema completo de criação de personagem
- 4 classes jogáveis: Guerreiro, Mago, Ladino, Paladino
- Sistema de combate com críticos e defesa
- Sistema de inventário com múltiplos tipos de itens
- Sistema de NPCs com diálogos
- Sistema de missões com 4 tipos diferentes
- Mapa do mundo com 8 locais exploráveis
- Sistema de experiência e leveling
- Sistema de moeda (Ouro)
- Habilidades únicas por classe
- Barras de HP, Mana e Stamina
- Salvamento e carregamento de jogo
- UI responsiva para desktop e mobile
- API REST backend em Java/Spring Boot
- Banco de dados H2 (desenvolvimento)
- Suporte para MySQL (produção)

### Recursos do Frontend
- Interface moderna com tema dark
- Animações suaves
- Notificações de eventos
- Modal para inventário, mapa e missões
- Log de combate em tempo real
- Atalhos de teclado (I, M, Q)

### Recursos do Backend
- 8 endpoints para Jogadores
- 5 endpoints para Inimigos
- 5 endpoints para Itens
- 6 endpoints para Missões
- 4 endpoints para NPCs
- Sistema de combate servidor
- Leveling automático
